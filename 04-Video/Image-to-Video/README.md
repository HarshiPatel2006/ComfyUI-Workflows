# Image to Video — ComfyUI workflows

Image-to-video (img2video) workflows, including first/last-frame, keyframe and low-VRAM variants: MiniMax H3, Wan 2.1 / 2.2, HunyuanVideo and 1.5, LTX-Video / LTX-2 / LTX-2.5, Kandinsky 5 / 6, CogVideoX, Pyramid Flow, DynamiCrafter / ToonCrafter, SVD, Cosmos, Capybara, Causal Forcing and AnimateDiff.

### No ComfyUI workflow found (this slice)

No authentic ComfyUI workflow was found, so nothing was fabricated:

- **Open-Sora Plan v1.2 I2V**, **Step-Video TI2V**, **Allegro TI2V** — no ComfyUI workflow found.
- **VideoCrafter1 I2V 512/1024**, **VGen / I2VGen-XL**, **VGen VideoComposer** — no maintained ComfyUI workflow.
- **DynamiCrafter 256/512** — same graph as `dynamicrafter-1024-img2video` with a smaller checkpoint (not duplicated).
- **AnimateDiff SparseCtrl** — no official workflow JSON published.
- **SVD-XT / SVD-XT 1.1** — load in `svd-img2video` or `svd-xt-sdxl-txt2img2video` by swapping the checkpoint.
- **HunyuanVideo 1.5 I2V step-distilled** — no separate graph; loads in the 1.5 I2V workflow.
