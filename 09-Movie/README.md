# AI Short Film Pipeline — ComfyUI workflows

An end-to-end AI short-film pipeline: Krea 2 storyboards and character sheets feed a MiniMax H3 reference-to-video chain that renders a multi-scene film.

**Start here:** [QUICK_START.md](QUICK_START.md) for the 5-minute version, [SETUP_GUIDE.md](SETUP_GUIDE.md) for the full guide, and [LINKS.md](LINKS.md) for model and node downloads. The main workflow is [`short-film-director-pipeline-krea-minimax-h3.json`](short-film-director-pipeline-krea-minimax-h3.json). [`Short-Film-Projects/`](Short-Film-Projects) holds the storyboard and film files from finished shorts made with it.
