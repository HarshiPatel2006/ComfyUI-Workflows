HOW TO INSTALL
--------------
1. Read SETUP_GUIDE.md
2. Install custom nodes via Git URL (especially):
   https://github.com/CodingWithShahzaib/ComfyUI-Krea-MultiShot-Stills
   https://github.com/ethanfel/ComfyUI-MiniMaxH3-Contex-Loop
3. Download models (links in SETUP_GUIDE)
4. Copy sample_assets into ComfyUI/input/
5. Load the JSON in ComfyUI

PIPELINE
--------
Character sheet -> Krea Multi-Shot V2 -> Scene Board Grid -> MiniMax H3 Contex Loop film

Toggle KREA vs H3 with the PIPELINE SWITCH (rgthree). Only one branch at a time.
